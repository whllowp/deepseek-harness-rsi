# Agent Note: 自进化守护核的长期知识库

Status: implemented

[English](2026-11-04-dual-core-rsi-knowledge-base.md) | 中文

## Problem

[后台自我进化的设计](2026-11-02-dual-core-rsi-background-evolution-panel.zh.md)给每次蒸馏的输入只有最新会话的有界摘要和两个当前世代：策略世代被替换后，产出它的那些教训随被归档的世代一起离开蒸馏器输入，守护核可能重新学习——甚至重新提出——早前循环已经确立或拒绝过的东西。会话关闭、摘要滚动，没有任何持久的东西记录一个候选为何失败。

## Decision

`dual_core_rsi` 存储域新增 `knowledge` 表，累积单行条目，分三种：采纳策略时沉淀 `insight`（自动采纳或人类合入，携带理由与得分）；评估候选未过门或人类拒绝时沉淀 `rejection`（提了什么、现策略为何胜出）；自我修复事件落定时沉淀 `repair-lesson`（哪里坏了、守护核如何恢复）。沉淀时归一化并截断每行，跳过完全相同的（种类， 文本）重复，超过 `knowledgeMaxEntries` 逐出最旧条目；沉淀并入调用方既有的持久提交，知识从不单独落盘。`RsiDistillInput` 携带最新 `knowledgePromptLines` 条（时间正序），蒸馏任务附带上它们并给出"建立在它们之上、没有新证据不得重提被拒绝方向"的指令。`activity` Remote、自进化面板的 Knowledge 区与 `/rsi knowledge` 以同一顺序（最新在前）展示这些条目。

## Consequences

知识跨世代复利：观测台的质量爬坡按沉淀顺序存入六条——三条洞察、一条拒绝教训、两条修复教训——每次后续蒸馏都会读到。饱和与内容去重跳过不沉淀任何东西（其结局是算术事实而非教训），保持知识库信号密集；逐出保证其有界。`consult` 下的人类决策留下与自动决策同种类的教训，仅文本不同，因此组合切换策略不丢失记忆。蒸馏提示词增加一个受 `knowledgePromptLines` 约束的段落；存储域保持版本 1，因为知识表与计数器是可增的可选状态。

## Alternatives considered

以归档世代代替知识表作为输入：被否决，归档携带完整产物集，提示词会随历史而非随有用教训增长，且拒绝理由——最有价值的教训——在循环记录而非产物里。复用事件表作为蒸馏输入：被否决，事件是带计数器与恢复动作的运营记录，而召回需要带去重与逐出的精选单行教训，不应让事件 schema 承担。在基准或台账内沉淀：被否决，知识必须在没有任何策略被采纳时也存在（纯失败会话仍有教训），因此它属于循环结算本身。
